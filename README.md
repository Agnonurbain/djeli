# 🎓 Djeli — Prof Chibi

> Le mentor intelligent ivoirien. Tuteur IA du collège à l'université.

**Djeli** est une PWA éducative qui accompagne les élèves ivoiriens dans leur apprentissage grâce à un agent IA adaptatif, un avatar Chibi animé, et une pédagogie ancrée dans le contexte local.

## Stack

Next.js 14 · TypeScript · Tailwind CSS · Supabase · Gemini 1.5 Pro · LangGraph · Rive · CinetPay

## Démarrage rapide

```bash
cp .env.example .env.local
# Remplir les variables d'environnement
npm install
npm run dev
```
